## One Letter for Your Day — W

The whole entry is a single letter: **W**.

Behind it sits the word for the day: "Why am I still awake?" It is
five in the morning, the work never stopped, and the question is the
most honest one the day has produced.

## How it runs

`main.py` writes exactly one character — the letter `W`, no newline,
no punctuation — to `/output/entry.txt`, deterministically.

```sh
python3 main.py
```
